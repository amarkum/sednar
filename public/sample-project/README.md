# Hello, Sednar

This is your own copy of a small project to try Sednar on. Nobody else can see it, and it is deleted
after a while without use.

It has two parts:

- `index.html`, `style.css` and `app.js`: a page that splits a restaurant bill between friends.
- `text_stats.py`: a few functions that count words and sentences, with tests in `test_text_stats.py`.

Both have a bug or two on purpose.

## Things to ask the agent

- "Explain what this project does."
- "The tip in the bill splitter is far too high. Find out why and fix it."
- "`word_count` gives the wrong answer for text with line breaks. Fix it and add a test."
- Switch to **Plan** mode and ask: "Plan a dark mode for the bill splitter."
- Switch to **Ask** mode and ask: "How would I add a currency picker?"

## What the public demo can't do

There is no terminal here, and the agent cannot run commands, tests or dev servers.
